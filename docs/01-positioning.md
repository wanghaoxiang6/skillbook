# Positioning

SkillBook turns external sources into reviewed, contextual, versioned updates to your AI skill tree.

SkillBook 把外部资料变成经过审查、结合上下文、可版本管理的 AI Skill 树更新。

它不是普通 Prompt 仓库、资料收藏夹、简单总结器，也不是自动污染 Skill 的生成器。它是 Source-to-Skill Compiler、Skill Intake Router、Skill Evolution System 和 Context Book for AI Agents。
