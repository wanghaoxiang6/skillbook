# Onboarding

SkillBook's first-run experience should make the product useful before the user understands every internal concept.

## First Run

```bash
skillbook init
skillbook onboard
skillbook interview
skillbook profile
skillbook gaps
skillbook recommend-libs --from-profile --from-gaps
```

## What Each Step Does

- `init` creates the file structure.
- `onboard` writes a local checklist.
- `interview` asks a few high-value questions and creates a profile proposal.
- `profile` summarizes the current project.
- `gaps` shows confirmed or inferred skill gaps.
- `recommend-libs` suggests public open-source libraries that fit the user's current context.

## Product Principle

Do not ask the user to understand SkillBook before SkillBook provides value. Start with user identity, current focus, gaps, and useful library recommendations.
