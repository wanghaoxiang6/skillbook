# Skill Quality Standard

正式 Skill 必须满足：

1. 只做一件主任务
2. 有明确触发场景
3. 有输入要求
4. 有执行步骤
5. 有禁止行为
6. 有输出格式
7. 有 examples
8. 有 evals
9. 有 sources
10. 能被导出到至少一个平台
11. 不超过合理长度
12. 不和用户 decisions 冲突

没有 evals 的 Skill 只能算 draft。没有 sources 的 Skill 不能升为 active。没有用户确认的 proposal 不能 apply 到正式 Skill。

Skill 进化不是变长，而是变准。新增规则必须能测试，案例不能伪装成规则，灵感不能伪装成流程。
