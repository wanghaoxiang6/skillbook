# MVP Roadmap

## V1

- Local TypeScript CLI
- Markdown/YAML/JSON files
- Source Card
- Update Proposal
- Draft apply
- Usage logs
- Evolution Proposal
- Export placeholders
- User interview and profile evolution proposals
- Library Scout recommendations from public GitHub and local profile/gaps

## Later

- Optional real LLM providers
- Better source parsing
- Richer profile evidence extraction from chat logs and issue trackers
- Vector store integration
- GitHub read-only repo analysis
- Optional GitHub authorization with minimum scopes, only after the public-search flow is stable
- UI only after CLI workflow is stable
