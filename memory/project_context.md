## README Summary
# SkillBook

**A Source-to-Skill Compiler & Evolution System**

SkillBook turns external sources into reviewed, contextual, versioned updates to your AI skill tree.

SkillBook 把外部资料变成经过审查、结合上下文、可版本管理的 AI Skill 树更新。

## It Is Not

- 不是普通 Prompt 仓库
- 不是资料收藏夹
- 不是简单总结器
- 不是自动污染 Skill 的生成器

## It Is

- Source-to-Skill Compiler
- Skill Intake Router
- Skill Evolution System
- Context Book for AI Agents

SkillBook 就像一本不断进化的“个人需求之书”。当用户丢入文章、项目、视频或想法时，系统不会直接总结，而是先判断它和这本书有没有关系。如果有，它会顺着目录找到应该放入的 Skill 位置，再判断它应该变成 Rule、Example、Eval、Warning、Reference，还是 Rejected。最后生成可审查的 `update_proposal.md`。

```mermaid
flowchart TD
    A[External Source<br/>Article / Repo / README / Video Transcript / Case] --> B[Source Reader]
    B --> C[Source Card Generator]
    C --> D[Intake Router]

    E[Context Book<br/>user_profile / project_context / preferences / decisions] --> D
    F[Skill Index<br/>skill_tree.yaml / skill_index.yaml] --> D
    G[Current Project Profile<br/>README / package.json / docs / src summary] --> D

    D --> H{Intake Decision}

    H -->|Reject| I[Rejected Record]
    H -->|Reference Only| J[Reference Entry]
    H -->|Update Existing Skill| K[Update Proposal]
    H -->|Create New Skill
